# Qobe CRM para Windows

Instalador e atualizações do **Qobe CRM** para Windows. Este repositório não tem código-fonte: só a receita de
montagem e as versões publicadas.

**Baixar:** [última versão](https://github.com/Cast4nha/qobe-crm-windows/releases/latest) → `Qobe-CRM_X.Y.Z_x64-setup.exe`.

Depois de instalado, o programa se atualiza sozinho a cada versão nova (avisa, baixa e reinicia).
Na primeira instalação o Windows pode mostrar "Editor desconhecido": clique em **Mais informações → Executar assim mesmo**.
